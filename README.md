# Clima

El clima de cualquier lugar: ahora, hoy por franjas y los próximos días. Una sola página, sin servidor ni claves: cada navegador consulta directo a las fuentes.

- Pronóstico: [Open-Meteo.com](https://open-meteo.com/), licencia [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Estaciones medidas de Córdoba: FUENTE: Portal de Información Hídrica de Córdoba.

Se publica en https://clima.entresijo.org. No se edita acá: se genera con `panel.py --publico` desde el panel del clima.
